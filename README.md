# Queuebot

Telegram-бот для очередей и крестиков-ноликов.
Один экземпляр обслуживает разные группы и личные чаты. Регистрация открыта:
пользователь становится известен боту при первом взаимодействии.

Очереди поддерживают запись кнопками, выход, пропуск следующего участника,
переход в конец, блоки, приоритеты, перераспределение при переполнении блока,
ручное управление и еженедельную очистку. Администраторы могут задавать имена
участников для своей группы. Игры работают в группах.

Исходный код: [MixelTe/queuebot](https://github.com/MixelTe/queuebot).
Поддерживаются long polling, webhook с собственным сервером и WSGI-хостинг
без фоновых задач: в последнем случае автоочистку запускает внешний ping URL.

- [Развёртывание и разработка](docs/DEVELOPER.md)
- [Инструкция пользователям и администраторам групп](docs/USERS.md)

Требуется Python 3.12+. Зависимости устанавливаются из `requirements.txt`.
Проект создан через `bafser init_project` после установки `bafser` и `bafser-tgapi`;

Каждый экземпляр использует собственную БД и собственный токен.
